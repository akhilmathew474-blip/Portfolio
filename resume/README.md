# Resume folder

Put your resume here, named exactly:

    akhil-mathew-resume.pdf

Then open `index.html`, find the `<section ... id="resume" ... data-resume-ready="false">` line
and change `"false"` to `"true"`. The "Resume coming soon" message is replaced by a working download button.

File names are case-sensitive on GitHub Pages. Use lowercase exactly as shown.
